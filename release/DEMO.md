# SpireTween Showcase

Run SpireTweenDemo to explore all 33 supplied animation templates. Each card has
Play / Restart and Stop & Restore controls. Scroll to see text entrances, looping
text, emphasis, visual entrances, interaction feedback, and continuous motion.

This is a standalone application; Godot and the addon are not needed to run it.
The paid addon includes the reusable templates, the full tween API, editor
authoring and preview, and a matching source archive. One purchase includes a
lifetime license and all future updates, including major versions.

For bug reports and usage questions, use
[GitHub Issues](https://github.com/Houtamelo/spire_tween_gdscript/issues).
The author checks GitHub daily and prioritizes bug fixes over all other SpireTween
work. Most issues are expected to be resolved within 72 hours, though the author
reserves the right to take up to 14 days. The itch.io community is checked from
time to time.

`demo.json` records the source snapshot and export engine. `SHA256SUMS` records
file hashes. The project is MIT licensed; see `LICENSE`. Dependency notices and
required dependency sources are under `third_party/`.

macOS builds use ad-hoc signatures and are not notarized. See the
[godot-rust distribution guidance](https://godot-rust.github.io/book/toolchain/export-mac-and-ios.html)
if macOS requires local approval or re-signing of the downloaded application.
